# Spec: Output Optimization & PDF Generation

## Summary
This plan addresses the user's request to:
1.  Remove conversational fillers (e.g., "Okay, as a contributor...") from the generated paper.
2.  Standardize and sort the references section.
3.  Generate a formatted PDF document.

## Current State Analysis
- **Conversational Fillers**: controlled by `LEAD_AUTHOR_WRITING_PROMPT` in `prompts/system_prompts.py`. The LLM tends to be chatty.
- **References**: Currently generated by the LLM, leading to potential inconsistency and lack of sorting.
- **PDF Output**: Currently only Markdown and JSON are saved in `SixAgentWorkflow._save_paper` in `agents/core.py`. `weasyprint` is available in the environment.

## Proposed Changes

### 1. System Prompt Optimization
**File**: `prompts/system_prompts.py`
- Modify `LEAD_AUTHOR_WRITING_PROMPT`:
    - Add strict instruction: "**Direct Start**: Do not output any conversational filler. Start directly with the Paper Title."
    - Change citation style to **(Author, Year)** to facilitate alphabetical sorting of the bibliography.
    - Instruct the LLM **NOT** to generate the final "References" list (we will do it programmatically to ensure perfection).

### 2. Logic Enhancements in `agents/core.py`
**File**: `agents/core.py`

#### `LeadAuthorAgent.write`
- Add post-processing to strip any remaining conversational text at the beginning (e.g., regex to find the first `# Title`).

#### `SixAgentWorkflow`
- **New Helper**: `_format_bibliography(papers: List[Dict]) -> str`
    - Sort papers alphabetically by the first author.
    - Format each paper into a standard string (e.g., APA style: Author. (Year). Title. Source.).
    - Return the formatted "## References" section.
- **New Helper**: `_generate_pdf(md_content: str, output_path: str)`
    - Convert Markdown to HTML using `markdown`.
    - Apply CSS for academic formatting (font, margins, justification).
    - Use `weasyprint.HTML(string=html).write_pdf(output_path)` to generate the PDF.
- **Update `_save_paper`**:
    - Call `_format_bibliography` and append it to `project.final_paper`.
    - Save the updated Markdown.
    - Call `_generate_pdf` to save the PDF version.

## Assumptions & Decisions
- **Citation Style**: We switch to **(Author, Year)** in-text citations to allow for **alphabetical sorting** of the bibliography without mismatching numeric indices.
- **PDF Engine**: We use `weasyprint` as it is already in the dependency list.
- **Formatting**: We will use a simple, clean CSS for the PDF (Times New Roman-like font, proper headers).

## Verification Plan
1.  **PDF Test**: Run a small script to verify `weasyprint` works in the current environment.
2.  **Workflow Test**: Run a full cycle (or a mock final step) to verify:
    - No chatter at the start.
    - Bibliography is sorted and appended.
    - PDF is generated in `output/`.
