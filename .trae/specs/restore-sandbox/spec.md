# Restore Data Analysis Sandbox Spec

## Why
The Data Analysis Agent is failing to generate charts because the `tools/sandbox.py` module is missing. This module is responsible for executing the Python code generated by the LLM (both for crawling and analysis) and capturing the output/figures. The user specifically noted that charts are not being drawn.

## What Changes
- Create `tools/sandbox.py`.
- Implement `ExecutionResult` class to structure execution outputs.
- Implement `PythonSandbox` class:
  - `execute(code)` method to run arbitrary Python code using `exec`.
  - Capture `stdout` and `stderr`.
  - Inject a `save_figure(filename)` function into the execution scope to intercept `matplotlib` plots and save them to the output directory.
  - Handle exceptions and return formatted errors.
- Implement `DataAnalyzer` class (as a placeholder/wrapper) to satisfy `tools/__init__.py` imports, ensuring backward compatibility.

## Impact
- **Affected specs**: None (Restoration).
- **Affected code**: `tools/sandbox.py` (New), `tools/__init__.py` (Verify).

## ADDED Requirements
### Requirement: Sandbox Execution
The system SHALL provide a `PythonSandbox` that can execute generated Python code in the local environment.

### Requirement: Figure Capturing
The sandbox SHALL provide a `save_figure` function to the executing code, which saves the current `matplotlib` figure to the specified output directory and tracks the file path.

### Requirement: Error Handling
The sandbox SHALL capture exceptions during execution and return them in the `ExecutionResult`.

## MODIFIED Requirements
None.
